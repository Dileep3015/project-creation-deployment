PAGE 2 · GITHUB & DEPLOYMENT

5. Prepare the project

requirements.txt .gitignore README.md
pip freeze > requirements.txt git init git add . git commit -m "Initial project"

6. Upload to GitHub

VSVS Code → GitGit → GHGitHub Repo
git remote add origin <repository-url> git branch -M main git push -u origin main
GitHub stores the source code and connects the project to deployment.
